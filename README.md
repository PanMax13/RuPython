# RuPython - Русский интерпретатор Python

RuPython - это экспериментальный интерпретатор, который позволяет писать код на русском языке с использованием ключевых слов и операций на кириллице.

## Особенности

- 🎯 **Русские ключевые слова**: `вывести`, `равно`, `меньше`, `больше`
- 🔢 **Русские математические операции**: `плюс`, `минус`, `умножить`, `делить`
- 📝 **Переменные**: поддержка букв, цифр и `_` в идентификаторах
- 🧮 **Арифметические операции**: сложение, вычитание, умножение, деление
- ⚖️ **Операции сравнения**: сравнение чисел
- 🔤 **Вывод данных**: команда для вывода результата
- 💻 **Запуск из консоли**: `rupython filename.rupy`
- 🔄 **Обновление из GitHub**: `rupython --update`
- 💬 **Комментарии**: строки и хвосты строк через `#`

## Установка

Требования:
- Python 3.x
- Git

### Установка одной командой

```bash
curl -fsSL https://raw.githubusercontent.com/PanMax13/RuPython/main/install.sh | bash
```

Установщик клонирует проект в `~/.rupython` и создает команду `rupython` в `~/.local/bin`.
Если `~/.local/bin` еще не находится в `PATH`, установщик сам добавит его в профиль shell (`~/.zshrc`, `~/.bashrc`, `~/.bash_profile` или `~/.profile`).

После установки откройте новый терминал и запускайте файлы из любой папки:

```bash
rupython filename.rupy
```

### Ручная установка для разработки

```bash
git clone https://github.com/PanMax13/RuPython.git
cd RuPython
chmod +x rupython
```

## Использование

Создайте файл `program.rupy`:

```python
x = 10
y = 30

вывести x меньше y
```

Запустите интерпретатор:

```bash
rupython program.rupy
```

Команда работает из любой директории, как обычный `python`:

```bash
cd ~/Desktop
rupython my_program.rupy
```

Из папки проекта можно запускать без установки:

```bash
./rupython program.rupy
```

Также можно читать код из stdin:

```bash
echo "вывести 10 плюс 20" | rupython -
```

или через старую точку входа:

```bash
python main.py program.rupy
```

Проверить версию:

```bash
rupython --version
```

Обновить язык из GitHub:

```bash
rupython --update
```

## Синтаксис языка

### Ключевые слова

| Русское слово | Английский аналог | Описание |
|--------------|-------------------|----------|
| `вывести` | `print` | Вывод значения на экран |
| `плюс` | `+` | Сложение |
| `минус` | `-` | Вычитание |
| `умножить` | `*` | Умножение |
| `делить` | `/` | Деление |
| `равно` | `==` | Сравнение на равенство |
| `больше` | `>` | Сравнение больше |
| `меньше` | `<` | Сравнение меньше |
| `и` | `&&` | Логическое И |
| `или` | `\|\|` | Логическое ИЛИ |
| `не` | `!` | Логическое НЕ |

### Комментарии

```python
# это комментарий
вывести 10 плюс 20 # это тоже комментарий
```

### Типы данных

- **Числа**: целые (`42`) и дробные (`3.14`)
- **Булевы значения**: `True`, `False` (при сравнении)
- **Переменные**: идентификаторы из букв, цифр и символа `_`

### Операции

#### Арифметические операции
```
выражение плюс выражение
выражение минус выражение
выражение умножить выражение
выражение делить выражение
```

#### Операции сравнения
```
выражение равно выражение
выражение больше выражение
выражение меньше выражение
```

#### Логические операции
```
не выражение
выражение и выражение
выражение или выражение
```

#### Присваивание
```
переменная = выражение
```

#### Вывод
```
вывести выражение
```

### Приоритет операций

1. **Высокий**: умножение и деление
2. **Средний**: сложение и вычитание
3. **Низкий**: операции сравнения
4. **Еще ниже**: `не`
5. **Ниже `не`**: `и`
6. **Самый низкий**: `или`

Пример:
```
вывести 10 плюс 20 умножить 2
# Результат: 50 (сначала 20 * 2 = 40, потом 10 + 40)
```

## Архитектура

Проект состоит из следующих модулей:

### 1. Tokenizer (Tokenizer.py)
**Задача**: Лексический анализ - разбор исходного кода на токены.

- Читает исходный код посимвольно
- Распознает ключевые слова, числа, идентификаторы и операторы
- Преобразует русские слова в токены

**Основные методы**:
- `tokenize()` - главный метод разбора
- `identifier()` - парсинг идентификаторов
- `number()` - парсинг чисел
- `skip_whitespaces()` - пропуск пробелов

### 2. Parser (Parser.py)
**Задача**: Синтаксический анализ - построение абстрактного синтаксического дерева (AST).

Использует метод **рекурсивного спуска**.

**AST узлы**:
- `Numbers` - числовые литералы
- `Variable` - переменные
- `BinaryOperation` - бинарные операции
- `Compare` - операции сравнения
- `LogicalOperation` - логические операции
- `UnaryOperation` - унарные операции
- `Assign` - присваивание
- `Print` - вывод

**Основные методы**:
- `parse()` - главный метод парсинга
- `factor()` - парсинг простых выражений
- `term()` - парсинг умножения/деления
- `expr()` - парсинг сложения/вычитания
- `comparison()` - парсинг сравнений
- `logical_not()` - парсинг логического НЕ
- `logical_and()` - парсинг логического И
- `logical_or()` - парсинг логического ИЛИ
- `statement()` - парсинг операторов

### 3. Interpreter (Interpritator.py)
**Задача**: Выполнение программы.

Использует паттерн **Visitor** для обхода AST.

**Основные методы**:
- `interpret()` - главный метод интерпретации
- `visit()` - автоматический выбор метода по типу узла
- `visit_BinaryOperation()` - выполнение арифметики
- `visit_Compare()` - выполнение сравнений
- `visit_LogicalOperation()` - выполнение логических операций
- `visit_UnaryOperation()` - выполнение унарных операций
- `visit_Print()` - вывод на экран
- `visit_Assign()` - присваивание переменных
- `visit_Numbers()` - обработка чисел
- `visit_Variable()` - получение значения переменной

### 4. Token (Token.py)
**Задача**: Представление токенов.

Простой класс для хранения типа и значения токена.

## Принцип работы

```
Исходный код
    ↓
Tokenizer (Лексический анализ)
    ↓
Список токенов
    ↓
Parser (Синтаксический анализ)
    ↓
AST (Абстрактное синтаксическое дерево)
    ↓
Interpreter (Выполнение)
    ↓
Результат
```

### Пример трансформации

**Исходный код:**
```python
вывести 10 плюс 20
```

**Токены:**
```
Token(PRINT, 'вывести')
Token(NUMBER, 10)
Token(PLUS, '+')
Token(NUMBER, 20)
```

**AST:**
```
Print
  └── BinaryOperation
       ├── Numbers(10)
       ├── op: PLUS
       └── Numbers(20)
```

**Результат:**
```
30
```

## Ограничения

⚠️ **Текущие ограничения языка**:

- Нет функций и процедур
- Нет циклов
- Нет условий (if/else)
- Нет массивов и структур
- Нет строковых литералов
- Поддержка только чисел (int и float)
- Идентификаторы не должны совпадать с ключевыми словами языка

### Добавление новой функциональности

1. **Добавить токен**: обновите `Tokenizer.py` для распознавания нового ключевого слова
2. **Добавить AST узел**: создайте новый класс в `Parser.py`
3. **Добавить парсинг**: создайте метод парсинга для нового узла
4. **Добавить интерпретацию**: создайте метод `visit_ИмяКласса` в `Interpreter.py`
