# RuPython - Русский интерпретатор Python

RuPython - это экспериментальный интерпретатор, который позволяет писать код на русском языке с использованием ключевых слов и операций на кириллице.

## Особенности

- 🎯 **Русские ключевые слова**: `вывести`, `равно`, `меньше`, `больше`
- 🔢 **Русские математические операции**: `плюс`, `минус`, `умножить`, `делить`
- 📝 **Переменные**: поддержка латинских символов в идентификаторах
- 🧮 **Арифметические операции**: сложение, вычитание, умножение, деление
- ⚖️ **Операции сравнения**: сравнение чисел
- 🔤 **Вывод данных**: команда для вывода результата

## Установка

Требования:
- Python 3.x


## Использование

Запустите интерпретатор с вашим кодом:

```bash
python main.py
```

### Примеры программ

#### Пример 1: Базовые арифметические операции
```python
вывести 10 плюс 20
# Вывод: 30

вывести 15 минус 5
# Вывод: 10

вывести 6 умножить 7
# Вывод: 42

вывести 20 делить 4
# Вывод: 5.0
```

#### Пример 2: Переменные и сравнения
```python
x = 10
y = 30

вывести x меньше y
# Вывод: True

вывести x равно y
# Вывод: False

вывести x больше y
# Вывод: False
```

#### Пример 3: Сложные выражения
```python
a = 5 плюс 10
b = 20 умножить 2

вывести a плюс b
# Вывод: 45

вывести b минус a
# Вывод: 25
```

## Синтаксис языка

### Ключевые слова

| Русское слово | Английский аналог | Описание |
|--------------|-------------------|----------|
| `вывести` | `print` | Вывод значения на экран |
| `плюс` | `+` | Сложение |
| `минус` | `-` | Вычитание |
| `умножить` | `*` | Умножение |
| `делить` | `/` | Деление |
| `равно` | `==` | Сравнение на равенство |
| `больше` | `>` | Сравнение больше |
| `меньше` | `<` | Сравнение меньше |
| `и` | `&&` | Логическое И |
| `или` | `\|\|` | Логическое ИЛИ |
| `не` | `!` | Логическое НЕ |

### Типы данных

- **Числа**: целые (`42`) и дробные (`3.14`)
- **Булевы значения**: `True`, `False` (при сравнении)
- **Переменные**: идентификаторы из латинских букв и символа `_`


### Приоритет операций

1. **Высокий**: умножение и деление
2. **Средний**: сложение и вычитание
3. **Низкий**: операции сравнения

Пример:
```
вывести 10 плюс 20 умножить 2
# Результат: 50 (сначала 20 * 2 = 40, потом 10 + 40)
```

## Архитектура

Проект состоит из следующих модулей:

### 1. Tokenizer (Tokenizer.py)
**Задача**: Лексический анализ - разбор исходного кода на токены.

- Читает исходный код посимвольно
- Распознает ключевые слова, числа, идентификаторы и операторы
- Преобразует русские слова в токены

**Основные методы**:
- `tokenize()` - главный метод разбора
- `identifier()` - парсинг идентификаторов
- `number()` - парсинг чисел
- `skip_whitespaces()` - пропуск пробелов

### 2. Parser (Parser.py)
**Задача**: Синтаксический анализ - построение абстрактного синтаксического дерева (AST).

Использует метод **рекурсивного спуска**.

**AST узлы**:
- `Numbers` - числовые литералы
- `Variable` - переменные
- `BinaryOperation` - бинарные операции
- `Compare` - операции сравнения
- `Assign` - присваивание
- `Print` - вывод

**Основные методы**:
- `parse()` - главный метод парсинга
- `factor()` - парсинг простых выражений
- `term()` - парсинг умножения/деления
- `expr()` - парсинг сложения/вычитания
- `comparison()` - парсинг сравнений
- `statement()` - парсинг операторов

### 3. Interpreter (Interpritator.py)
**Задача**: Выполнение программы.

Использует паттерн **Visitor** для обхода AST.

**Основные методы**:
- `interpret()` - главный метод интерпретации
- `visit()` - автоматический выбор метода по типу узла
- `visit_BinaryOperation()` - выполнение арифметики
- `visit_Compare()` - выполнение сравнений
- `visit_Print()` - вывод на экран
- `visit_Assign()` - присваивание переменных
- `visit_Numbers()` - обработка чисел
- `visit_Variable()` - получение значения переменной

### 4. Token (Token.py)
**Задача**: Представление токенов.

Простой класс для хранения типа и значения токена.

## Принцип работы

```
Исходный код
    ↓
Tokenizer (Лексический анализ)
    ↓
Список токенов
    ↓
Parser (Синтаксический анализ)
    ↓
AST (Абстрактное синтаксическое дерево)
    ↓
Interpreter (Выполнение)
    ↓
Результат
```

### Пример трансформации

**Исходный код:**
```python
вывести 10 плюс 20
```

**Токены:**
```
Token(PRINT, 'вывести')
Token(NUMBER, 10)
Token(PLUS, '+')
Token(NUMBER, 20)
```

**AST:**
```
Print
  └── BinaryOperation
       ├── Numbers(10)
       ├── op: PLUS
       └── Numbers(20)
```

**Результат:**
```
30
```

## Ограничения

⚠️ **Текущие ограничения языка**:

- Нет функций и процедур
- Нет циклов
- Нет условий (if/else)
- Нет массивов и структур
- Нет строковых литералов
- Нет комментариев
- Поддержка только чисел (int и float)
- Переменные только с латинскими символами
- Логические операции объявлены, но еще не реализованы в парсере

### Добавление новой функциональности

1. **Добавить токен**: обновите `Tokenizer.py` для распознавания нового ключевого слова
2. **Добавить AST узел**: создайте новый класс в `Parser.py`
3. **Добавить парсинг**: создайте метод парсинга для нового узла
4. **Добавить интерпретацию**: создайте метод `visit_ИмяКласса` в `Interpreter.py`
